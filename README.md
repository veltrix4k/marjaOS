
# marjaOS

**An experimental operating system project.**

A personal operating system development project focused on kernel development, boot architecture, and low-level systems programming.

---

## Overview

marjaOS is an independently developed operating system
project currently under active development.

## Architecture

- Kernel: C#
- Architecture: x86-64
- Bootloader: Custom / Cosmos-based (update as appropriate)
- Build system: .NET
